# 让任务栏适配深色壁纸

Windows 11 默认是浅色任务栏，在深色壁纸上会出现一条白带，左下角的搜索框更是显眼的白框。
程序提供了一键处理，换到别人电脑上也能用同样方式设置。

## 一键处理（推荐）

托盘右键 → **「任务栏适配深色桌面」**

它做两件事：

| 项目 | 注册表位置 | 值 |
|---|---|---|
| 任务栏 / 开始菜单改深色 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize` → `SystemUsesLightTheme` | `0` |
| 搜索框缩成图标 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Search` → `SearchboxTaskbarMode` | `1` |

设置后会向系统广播一次主题变更，任务栏立即刷新，不需要重启资源管理器。

## 搜索框那一步可能失败

部分机器的 `HKCU\...\CurrentVersion\Search` 键归 `SYSTEM` 所有，普通权限写不进去
（程序会弹提示「已改成深色；搜索框需要在设置里选仅搜索图标」）。两种补法：

1. **设置界面**：设置 → 个性化 → 任务栏 → 搜索 → 选「仅搜索图标」
2. **管理员命令行**：

```powershell
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Search" /v SearchboxTaskbarMode /t REG_DWORD /d 1 /f
```

（右键「终端(管理员)」运行；如果仍报拒绝访问，说明当前用户对该键没有写权限，
用设置界面最省事。）

## 手动全部设置（不装程序也能做）

1. 设置 → 个性化 → 颜色 → 「选择模式」选 **深色**
2. 同一页往下，「在开始菜单和任务栏上显示强调色」按喜好开关
3. 设置 → 个性化 → 任务栏 → 搜索 → **仅搜索图标**

## 说明

- 只改当前用户（`HKCU`），不影响其他账户，也不需要管理员
- 想恢复浅色：`SystemUsesLightTheme` 改回 `1`，搜索模式改回 `2`（完整搜索框）
- 应用内实现见 `src/dailywallpaper/apply/desktop_theme.py`
