## 上一版报告为什么反过来了

上一版报告的结论是「个性化那 45% 没有被证明有用」（纯个性化 0.572，低于纯探索 0.639）。那个结论测的是**一个缺陷**，不是个性化这条路：

1. 评分权重固定以 5.5 为中点（`(分数 − 5.5) / 4.5`）。这个库 366 条评分平均 4.55，65% 落在 5.5 以下，于是画像学到的是「大部分都不喜欢」——标签权重求和为负，`tag_affinity` 对几乎所有候选都返回中性以下，个性化那一半再也不能说「更像这张」。
2. 来源权重用的是**求和**，随图库规模增长。真实数据里 wallhaven 原始权重 −109，被 clamp 到端点，于是占候选 97% 的那个来源，每张图的来源分恒为 0.0。

两处都改为以用户自己的均值为中点、来源取收缩后的均值。改完纯个性化从 0.572 升到 0.680，本报告下面的表格就是修复后的结果。这条记录留在报告里，是因为它比任何单个指标都说明问题：一个被 clamp 压平的项，在读指标的人眼里长得像「这条路没用」。

## 成对比较（主结论）

5 折交叉验证：每折 80% 建画像、20% 只评估；每折里所有评分差 ≥1 的两两配对各问一次，共 11700 个问题。

准确率 = 「分数更高的那张，确实是你打分更高的那张」的比例。0.5 等于抛硬币。
标准差是折与折之间的波动，不是抽样误差。

| 排序策略 | 成对准确率 | 折间标准差 |
|---|---|---|
| 纯探索 | 0.639 (±0.040) |
| 纯个性化 | 0.680 (±0.024) |
| 25/75 纯混合 | 0.696 (±0.036) |
| 25/75 + 惩罚（原状） | 0.681 (±0.031) |
| 25/75 + 糖水判别式 | 0.704 (±0.025) |

最好的策略：**25/75 + 糖水判别式**

## NDCG@5（5 折 × 每折 1–2 个候选池）

NDCG@5 按伪候选池（每池约 40 张，模拟一天的候选量）计算后取平均，共 **10 个池**；括号内是池与池之间的标准差。池子由折内的测试集重新发牌得到，所以每折都有自己的排名题，离散程度是真实的、不是恒为 0 的占位值。

| 排序策略 | NDCG@5 | 池间标准差 | 单次切分 Spearman |
|---|---|---|---|
| 随机（下限） | 0.530 (±0.045) | 0.000 |
| 纯探索 | 0.728 (±0.123) | 0.396 |
| 纯个性化 | 0.806 (±0.087) | 0.373 |
| 25/75 纯混合 | 0.816 (±0.099) | 0.443 |
| 25/75 + 惩罚（不含糖水模型） | 0.777 (±0.093) | 0.405 |
| 25/75 + 糖水判别式 | 0.824 (±0.103) | 0.463 |

最好的策略：**25/75 + 糖水判别式**

Spearman 来自单次 70/30 切分（整个测试集一条排名），只作方向参考；两种指标不一致时以成对比较为准。

## 真实历史（小样本）

程序实际应用过、且你评过分的壁纸：**n = 37**，模型分与你的评分的 Spearman = **0.423**。

样本量太小，这个数只能当方向参考，不能下结论。攒到 100 条以上才有意义。

## 局限

- 评估集的来源构成：wallhaven 97%、steam_workshop 1%、bing 0%。静态图占绝大多数，结论主要说明静态图的审美排序，不代表 Steam 动态壁纸。
- 离线回放测的是排序逻辑；它回答不了“换个来源能不能找到更好的图”。
- 有 1 张评分没有分析：视觉模型连续返回不合约的字段（重新编码后再试仍失败），这几张只能排除在指标之外。
- 四维分数完全相同的组数很多，说明模型对相近的图给出的分辩不出差别；排序里那部分名次由探索分和画像分决定，不是由画质分决定。
- 训练/测试按评分分层切分，同一张图不会同时出现在两侧；但同一位作者的同系列作品
  可能被分到两侧，会略微高估。
